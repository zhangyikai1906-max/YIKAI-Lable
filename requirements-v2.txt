# ────────────────────────────────────────────────────
# DINOv3 本地权重（无需联网，项目内已包含）
# ────────────────────────────────────────────────────
# 位置：dinov3/ 目录，含三个变体：
#   dinov3_vits16_pretrain_*.pth      82.5 MB  ← 默认推荐（RTX 2060）
#   dinov3_vits16plus_pretrain_*.pth 109.6 MB  （SwiGLU MLP，特征更强）
#   dinov3_vitb16_pretrain_*.pth     327.0 MB  （最强，显存需求高）
#
# 用法：DINOv3Engine(variant="vits16").load()   ← 自动发现权重文件
#
# 功能：
#   1. 注意力图检测（无监督）：CLS token 注意力热图 → bbox 提议 → SAM3 精分割
#   2. 少样本匹配检测：上传参考图 → patch 特征相似度 → 定位相同外观目标
#   3. 特征聚类：提取 CLS 特征 → KMeans 聚类 → 代表图预筛选

#   https://github.com/facebookresearch/sam2#model-checkpoints
# 启动前设置环境变量：
#   set SAM3_CHECKPOINT=D:\weights\sam2.1_hiera_small.pt
